# Grade Calculator & Unit Tests

A C# application featuring business logic for academic grade calculation and input validation, fully covered by automated unit tests using MSTest.

## Features
- Evaluates grade bands (e.g., Distinction, Pass) based on numeric scores.
- Validates score ranges to handle boundary conditions and invalid inputs.
- Implements automated unit testing following the AAA (Arrange, Act, Assert) pattern.

## Technologies Used
- C# / .NET
- MSTest Framework

## How to Run Tests
Clone the repository and run tests from the terminal:

dotnet test
